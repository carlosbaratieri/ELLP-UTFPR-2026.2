## 1. Conceitos básicos

### 1.1 O que é programação?

Programação é o processo de criar instruções para que um computador execute determinadas tarefas. Essas instruções são escritas utilizando linguagens de programação e permitem desenvolver programas, jogos, aplicativos e diversos outros sistemas.

### 1.2 O que é Python?

Python é uma linguagem de programação de alto nível, conhecida por sua sintaxe simples e fácil leitura. É utilizada em diversas áreas, como desenvolvimento de software, automação, análise de dados, inteligência artificial e desenvolvimento web.

### 1.3 Primeiro programa

O primeiro contato com uma linguagem de programação geralmente é feito por meio de um programa que exibe a mensagem "Olá, mundo!".

Em Python, utilizamos a função `print()` para exibir informações na tela:

```python
print("Olá, mundo!")
```
